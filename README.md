# InfoHub · 多源信息聚合检索工具

一次关键词输入，并行检索 GitHub / Stack Overflow / 维基百科 / Hacker News 等 5 个数据源，
合并去重后统一呈现。支持来源筛选、相关度/时间排序、收藏与搜索历史（本地持久化）。

## 当前版本

v0.2 正式版（在线演示：infohub-kjp5203f2-jjewfg.vercel.app）
